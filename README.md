# NEXRAD / WSR-88D Interface Control Documents

This repository provides the **four latest Interface Control Documents (ICDs)** for the NEXRAD (WSR-88D) radar system. These documents are the authoritative technical references for developers, engineers, and researchers working with **Level II** and **Level III** radar data.

## Included Documents
- **Interface Control Document for the RPG to Class 1 User**
- **Interface Control Document for the RDA and RDP**
- **Interface Control Document for the Product Specification**
- **Interface Control Document for Archive II and User**

All documents are provided here for convenience in one place. They define the binary formats, message structures, product codes, scaling/offset conventions, and other specifications required to implement radar data decoders and processing tools.

## Source
The official distribution of these ICDs can be found on NOAA’s ROC site:  
👉 [NOAA ROC Interface Control Documents](http://www.test.roc.noaa.gov/interface-control-documents.php)

## Usage
- This repository is intended as a **reference archive** only.  
- Always consult the latest official release on the NOAA ROC site for authoritative updates.  
- Useful for projects involving:
  - Radar data decoders (Level II / Level III)
  - Visualization and analysis tools
  - Verification of product codes, units, ranges, and block layouts
