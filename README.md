# NEXRAD / WSR-88D Interface Control Documents

This repository mirrors a set of publicly available **Interface Control Documents (ICDs)** for the NEXRAD (WSR-88D) radar system.
## Official Source
The authoritative and most up-to-date versions of these documents are published by NOAA’s Radar Operations Center (ROC):

👉 https://www.roc.noaa.gov/interface-control-documents.php
